# Образы
## Dockerfile

**Dockerfile** - это главный файл, который описывает сборку Docker-образа.
**Директива** - это ключевое слово в верхнем регистре, которое определяет шаг сборки Docker-образа.

Директивы:
- `FROM` - указывает базовый образ.
- `RUN` - выполняет команду при сборке образа.
- `COPY` - копирует файлы в образ.
- `ADD` - добавляет файлы в образ.
- `WORKDIR` - задаёт рабочую директорию.
- `ENV` - задаёт переменную окружения.
- `ARG` - задаёт аргумент сборки.
- `EXPOSE` - указывает используемый порт.
- `CMD` - задаёт команду запуска контейнера.
- `ENTRYPOINT` - задаёт основную команду контейнера.
- `USER` - задаёт пользователя, от имени которого работает контейнер.
> **Это понятно**

# Контейнеры
## Архитектура

**Docker Daemon** - главный процесс Docker.
**Docker Client** - интерфейс командной строки.
**Docker API** - интерфейс общения CLI и движка.

## Команды

- `docker build` - сборка образа
- `docker images` - просмотр образа
- `docker pull` - получение образа
- `docker push` - отправка образа
- `docker tag` - создание тега для образа
- `docker history` - история образа
- `docker run` - запуск контейнера
- `docker ps` - просмотр контейнеров
- `docker stop` - остановка контейнера
- `docker logs` - просмотр логов
- `docker exec` - выполнение команды внутри контейнера
- `docker network` - работа с сетями Docker
**Все предельно ясно**
